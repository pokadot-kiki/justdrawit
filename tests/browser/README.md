# เทสเบราว์เซอร์จริง (CDP)

ต้อง build client ก่อน: `cd client && npm run build` แล้วรัน `npm run test:browser` จากโฟลเดอร์บนสุด (ราว 5 นาที)
สคริปต์เปิด server ทดสอบพอร์ต 3001 + Chrome headless แบบ `--mute-audio` เอง (ไม่แตะพอร์ต 3000) และปิด/ลบโปรไฟล์ชั่วคราวตอนจบ

| ไฟล์ | ตรวจอะไร |
|---|---|
| `mobile.mjs <กว้างxสูง> <ODDS>` | มือถือแนวตั้ง (เช่น 390x844, 375x667): หน้าแรก SET UP Leaderboard Solo ห้องรอ เกม สรุปตา จบเกม กลับห้องรอ — ไม่ล้น/ไม่ซ้อนทับ/ไม่ถูกบัง · คำเหนือกระดาน · รีเฟรชระหว่างสรุปผล · กลับห้องรอ |
| `mobile-team.mjs <กว้างxสูง>` | เหมือนกันแต่โหมดทีม 4 แท็บ |
| `refresh.mjs 1440x900 classic\|team [ODDS]` | รีเฟรชจริงระหว่างห้องรอ เลือกคำ ป้าย Mini Challenge วาด ทาย หน้าสรุปตา — ต้องอยู่ `/room/รหัส` หน้าเดิม ภาพ/บทบาทกลับมา คนวาดวาดต่อได้ |

ODDS = โอกาสสุ่ม Mini Challenge (1 = ทุกตา · 0 = ไม่มี)
| `refresh-solo.mjs 1440x900` | รีเฟรชจริงของ Solo: ช่วงเราวาด (ภาพ/คำ/ด่าน/ชีวิต/เวลากลับมา วาดต่อได้ รีเฟรชซ้ำ) · ช่วง AI วาด (เส้นที่วาดไปแล้วกลับมา ทายต่อได้) · ต่อ server ไม่ติดเกิน 30 วิ → กลับหน้าเริ่มเกม · Chrome เปิดด้วย `--disable-features=BackForwardCache` (ไม่งั้นหน้าเก่าที่ถูกแคชค้างสาย socket ทำให้ server คิดว่ายังออนไลน์) |
| `solo-wordbar.mjs 1440x900` | แถบคำ + กล่อง "AI คิดว่า/พิมพ์คำตอบ" ของ Solo ทุกช่วง: ช่วง 1 โชว์คำที่ต้องวาด · ช่วง 2 โชว์หมวด/คำใบ้เท่านั้น · หน้าต่างเฉลยช่วง 2 ไม่ย้อนไปโชว์ของช่วง 1 · ขึ้นด่านใหม่ไม่มีของเก่าค้าง · รีเฟรชกลางช่วง 1 และช่วง 2 ได้ข้อมูลถูกช่วง |
| `cursor.mjs 1440x900` | เคอร์เซอร์บนกระดาน: ปากกา/ยางลบ = วงกลม PNG ตามขนาดแปรง ≤ 32×32 จุดปลายกลางวง มีเส้นดำ+ขาว · ถังสี/รูปทรงคนละแบบ · ลงท้าย `crosshair` เสมอ · คนวาดไม่ได้ใช้เคอร์เซอร์ปกติ · ทำภาพขยายบนพื้นขาว/ม่วง/เข้ม |
| `balance.mjs` | ความสมดุลที่ 1440×900 · 1366×768 · 1024×768 · 1180×740: หน้าแรก (แผง Leaderboard สูง/ขอบบนล่างเท่าแผงซ้าย · ตารางเลื่อนในกรอบ หัว/เดือน/แท็บไม่เลื่อน หัวตารางค้าง · ป้าย "คุณ" · ไม่เลื่อนหน้า) และหน้าเกม (แผงผู้เล่นเริ่มระดับแถบคำ · ล่างผู้เล่น = ล่างแถบเวลา = ล่างแผงขวา · ไม่เลื่อน) ทั้งคนวาด/คนทาย |
| `setup-solo.mjs <กว้างxสูง>` | หน้า SET UP: วางกล่องตามภาพ `setup-screen.png` (ซ้ายตั้งค่า · ขวาบนแข่งเดี่ยว/แข่งทีม · ขวาล่างกล่อง AI · ไม่ทับกัน · 390px เรียงบนลงล่าง) · ตัวเลขผู้เล่นตรงกับ server · ซ่อน MULTIPLAYER VS AI · เลือก "แข่งกับ AI" ซ่อนจำนวนรอบ/เวลาวาด/ประเภทห้อง แทนด้วย "เริ่มที่ระดับ" + กล่องกติกา Solo (ตัวเลขตรงกับ server) · สลับกลับ classic/ทีม ค่ารอบ/เวลา/ความยาก(ผสม)กลับมาตามที่เคยตั้ง · ความสูงการ์ดไม่กระโดด · ไม่เลื่อนที่ 1440×900/1366×768/1024×768 |
| `mpai.mjs <กว้างxสูง>` | Multiplayer vs AI 2 แท็บ: การ์ด MULTIPLAYER VS AI ใน SET UP · ห้องรอโหมด "แข่งกับ AI" · ช่วง 1 คำเดียวกัน AI ดูภาพทุก 5 วิ คำทายขึ้นเป็นแชทของเจ้าของ ทายถูก = ม่านรอเพื่อน+เครื่องมือล็อก · เพื่อนเห็นแค่ x/y ไม่เห็นคำทาย/ภาพ · รีเฟรชกลางช่วง 1 · แกลเลอรีเมื่อ AI ถูกครบ · ช่วง 2 แชทร่วม (ผิดเห็นทุกจอตามลำดับ · ถูกเห็น ******) คนแรกถูกไม่จบช่วง · เฉลย · ตารางวาด/ทาย · ไม่ล้น/ไม่ซ้อน (พอร์ต 3051) |
| `leaderboard-year.mjs` | Leaderboard หน้าแรก + หน้าเต็ม (ทั้งสองแท็บ): dropdown เดือนไม่มี "ตลอดกาล" เหลือแค่ ม.ค.–เดือนปัจจุบันของปีนี้ ทุกตัวเลือกเป็นปีปัจจุบัน ค่าเริ่มต้น = เดือนปัจจุบัน |
| `solo-rank.mjs` | หน้าจบเกม Solo: ข้อความอันดับเป็น "ของเดือนนี้" (ไม่ใช่ "ตลอดกาล") และเลขอันดับคำนวณจากกระดาน solo เดือนปัจจุบันเท่านั้น (ไม่นับคะแนนเดือนก่อนที่สูงกว่า) — เล่นจริงจนแพ้ครบ 3 ชีวิตด้วยเวลาหมด (ปิดช่วงที่ 2 ไว้ให้ผลคงที่) |
| `team-options.mjs` | แข่งทีม 4 ทีม 8 แท็บ: เลือกจำนวนทีมใน SET UP · ทุกคนเข้าห้องเห็นคอลัมน์ทีมครบ 4 สี · จัดทีมเอง · ตั้งชื่อทีม (ตัวเอง/คนอื่น/หัวห้อง) ปุ่มเปลี่ยนชื่อไม่โผล่ให้คนไม่มีสิทธิ์ · ไม่ล้นจอทุกขนาดรวมมือถือ · เริ่มเกมแล้วชิปคะแนน 4 ทีมโชว์ชื่อที่ตั้งไว้ |
| `profile-editor.mjs [โฟลเดอร์ภาพ]` | หน้าแต่งโปรไฟล์ (เฟส A): 1440×900 / 390×844 / 320×640 ไม่ล้น · สองคอลัมน์/คอลัมน์เดียว · เลือกอวตาร ลูกเต๋า พิมพ์ชื่อแล้วพรีวิวเปลี่ยน · ยกเลิก/กากบาท/Esc/บันทึก · ในห้อง: ชื่อไม่เหมาะสมถูก server ปฏิเสธ · ทำซ้ำตอนล็อกอิน (server โหมดเทส) · ชิป coin (guest ชวนล็อกอิน / ล็อกอินเห็นยอดจาก server · แก้ localStorage แล้วยอดไม่เปลี่ยน) · พอร์ต 3012/3013 |
| `coin-notify.mjs [โฟลเดอร์ภาพ]` | แจ้งเตือน coin: เล่นเกมแข่งเดี่ยวจริง 3 คน (ล็อกอิน 2 + guest 1 คนละ browser context) · toast ตอนทายถูก/เป็นคนวาด/จบเกม · สรุป coin ท้ายเกมตรงกับยอดที่ server · guest เห็นข้อความชวนล็อกอิน · พอร์ต 3014 |
| `cosmetics.mjs [โฟลเดอร์ภาพ]` | เครื่องประดับ: สองคนคนละ browser context · แท็บ 6 แท็บและพรีวิวที่ 1440/390/320 · จำชุดหลังรีเฟรช · เข้าห้องแล้วอีกคนเห็นชุดครบทุกชั้น · เปลี่ยนชุดในห้อง (equip) · แถบคะแนนแบบย่อ (หมวก แว่น คอ) · หน้าจบเกมแบบเต็ม · พอร์ต 3015 |
