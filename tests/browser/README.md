# เทสเบราว์เซอร์จริง (CDP)

ต้อง build client ก่อน: `cd client && npm run build` แล้วรัน `npm run test:browser` จากโฟลเดอร์บนสุด (ราว 5 นาที)
สคริปต์เปิด server ทดสอบพอร์ต 3001 + Chrome headless แบบ `--mute-audio` เอง (ไม่แตะพอร์ต 3000) และปิด/ลบโปรไฟล์ชั่วคราวตอนจบ

| ไฟล์ | ตรวจอะไร |
|---|---|
| `mobile.mjs <กว้างxสูง> <ODDS>` | มือถือแนวตั้ง (เช่น 390x844, 375x667): หน้าแรก SET UP Leaderboard Solo ห้องรอ เกม สรุปตา จบเกม กลับห้องรอ — ไม่ล้น/ไม่ซ้อนทับ/ไม่ถูกบัง · คำเหนือกระดาน · รีเฟรชระหว่างสรุปผล · กลับห้องรอ |
| `mobile-team.mjs <กว้างxสูง>` | เหมือนกันแต่โหมดทีม 4 แท็บ |
| `refresh.mjs 1440x900 classic\|team [ODDS]` | รีเฟรชจริงระหว่างห้องรอ เลือกคำ ป้าย Mini Challenge วาด ทาย หน้าสรุปตา — ต้องอยู่ `/room/รหัส` หน้าเดิม ภาพ/บทบาทกลับมา คนวาดวาดต่อได้ |

ODDS = โอกาสสุ่ม Mini Challenge (1 = ทุกตา · 0 = ไม่มี)
