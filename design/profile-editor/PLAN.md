# แผนระบบแต่งโปรไฟล์

> ไฟล์นี้บน branch นี้มีแค่หัวข้ออัปโหลดรูป — แผนเต็ม (รอบ A–F, coin, ชั้นอวตาร) อยู่ในไฟล์ชื่อเดียวกันบน `main` ในเครื่องของผู้พัฒนา รวมกันตอน merge

## อัปโหลดรูปโปรไฟล์ — ซ่อนไว้ก่อน (13 ต.ค. 2026)

- **สถานะ:** ซ่อน ไม่ได้ลบโค้ด · สวิตช์ `PHOTO_UPLOAD_ENABLED = false` ที่ `client/src/featureFlags.js` ที่เดียว
- **เหตุผล:** ต้องเปิด Firebase Storage ก่อน (อาจต้องอัปเป็นแพ็กเกจ Blaze) และยังไม่มีระบบตรวจรูปไม่เหมาะสม
- **ตอนปิด:** ไม่มีปุ่มกล้องที่อวตารหน้าแรก · ไม่เปิดหน้าต่างอัปโหลด · ไม่ติดต่อ Storage เลย (ไม่มี error เรื่อง Storage โผล่) · หน้าแต่งโปรไฟล์/ห้องแต่งตัวเลือกได้แค่อวตารพิกเซล · ผู้เล่นที่เคยตั้งรูปไว้แล้วแสดงเป็นอวตารพิกเซลทุกที่ (`AvatarImage` ไม่ใช้ `photoUrl`) · ไม่ลบไฟล์เดิมใน Storage
- **วิธีเปิด:** (1) เปิด Firebase Storage + ตั้ง Storage Rules ให้เขียนได้เฉพาะ `avatars/<uid>/` ของตัวเอง (2) ตั้ง `VITE_FIREBASE_STORAGE_BUCKET` ฝั่ง client และให้ `/api/avatar/storage-status` ของ server ตอบ `ready` (3) เปลี่ยน `PHOTO_UPLOAD_ENABLED` เป็น `true` แล้ว build ใหม่ · ควรมีระบบตรวจรูปไม่เหมาะสมก่อนเปิดจริง
- ฝั่ง server ไม่ได้แก้ (ยังรับ `avatarPhoto` ได้ตามเดิม แต่หน้าเว็บไม่ส่งรูปใหม่และไม่แสดงรูป)
